ID selectors

The CSS ID selector matches an element based on the value of the element's id attribute. In order for the element to be selected, its id attribute must match exactly the value given in the selector.

Syntax


#id_value {
    /* ...  */
}

[id="id_value"] {
    /* ... */
}
